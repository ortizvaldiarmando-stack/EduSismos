    📖 ¿Cómo funciona EduSismos 2026?

    Detección de sismos reales: La app consulta cada 30 segundos la API del USGS para obtener sismos recientes en México (magnitud >= 4.5). Si detecta uno nuevo, activa la alarma real con los datos oficiales.

    Simulador educativo: Además, puedes activar sismos simulados para practicar protocolos.

    • 🔍 Monitoreo real (USGS) - sismos ya ocurridos, útiles para concienciación.
    • ⚡ Alerta inmediata con sonido potente, vibración y cuenta regresiva.
    • 📊 Historial unificado de eventos reales y simulados.
    • 🎛️ Personalización de sismos educativos.
    • 📍 Mapa interactivo con zonas sísmicas de México.

    ✅ Recomendaciones oficiales (Protección Civil)

    • Agacharse, Cubrirse y Agarrarse.
    • Identificar zonas de seguridad.
    • Tener plan familiar de emergencia.
