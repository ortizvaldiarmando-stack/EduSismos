# EduSismos 2026 – Alerta Sísmica Inclusiva

**EduSismos** es una aplicación web progresiva (PWA) que integra alerta sísmica en tiempo real, localización de personas y un simulador educativo, con un diseño universalmente accesible para personas con discapacidades visuales, auditivas, del habla o motoras.

## Características principales
- 🔴 Alerta sísmica en tiempo real (USGS)
- 📍 Localización GPS con envío por WhatsApp
- 🎓 Simulador educativo personalizable
- ♿ Accesibilidad universal (voz, vibración, alto contraste, teclado)
- 📊 Estadísticas y recomendaciones de evacuación

## Tecnologías
- HTML5, CSS3, JavaScript ES6
- Leaflet.js, Chart.js
- API USGS, Geolocation API, Web Audio API

## Instalación
Solo abre `index.html` en tu navegador favorito (Chrome, Firefox, Edge, Safari).
