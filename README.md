# EduSismos 2026

Aplicacion web de alerta sismica, localizacion de personas y educacion sismica.

## Funcionalidades

- Monitoreo de sismos reales en Mexico (datos oficiales de USGS)
- Envio de ubicacion por WhatsApp o SMS a contactos de emergencia
- Botones de panico con mensajes predefinidos
- Monitoreo automatico de ubicacion durante 8 horas
- Simulador educativo de sismos
- Accesibilidad universal (voz, vibracion, mensajes predefinidos)
- Mapa de zonas sismicas de Mexico

## Estructura

- `index.html` - Aplicacion completa
- `manifest.json` - Configuracion PWA
- `backend/server.js` - Backend para envio de SMS con Twilio
- `backend/package.json` - Dependencias del backend

## Como usar

1. Clona el repositorio
2. Abre `index.html` en un navegador moderno
3. Permite la geolocalizacion y las ventanas emergentes

## Como desplegar

- Frontend: GitHub Pages (rama main, carpeta raiz)
- Backend: Render, Railway o Fly.io
